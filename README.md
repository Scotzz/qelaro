# Qeralo — портфолио

Одностраничный статический сайт. Без сборки, фреймворков и внешних запросов: вся разметка, CSS и JS находятся в `index.html`, шрифты лежат рядом в `assets/`.

## Как посмотреть

Откройте `index.html` в браузере — сборка и локальный сервер не нужны.

При желании можно подать папку через любой статический сервер, например:

```sh
npx serve .
```

## Структура

```
index.html                  страница: разметка, CSS, JS
assets/fonts.css            только @font-face
assets/fonts/               Manrope (кириллица + латиница), OFL.txt
AGENTS.md                   заметки о проекте
```

## Особенности

- Самостоятельные шрифты Manrope (Variable, `wght` 200–800); кириллица и латиница в отдельных поднаборах. Лицензия — [SIL Open Font License](assets/fonts/OFL.txt).
- Иконки Solar Linear (480 Design, CC BY 4.0) встроены в страницу как SVG-спрайт; атрибуция указана в футере и в HTML-комментарии.
- Скролл-анимация 3D-сборки сделана чистым CSS-трансформом: JS лишь выставляет CSS-переменные `--p` и `--scroll`.
- Сайт читается и без JavaScript, поддерживает `prefers-reduced-motion` и светлую/тёмную тему.

## Лицензии

- Иконки Solar Linear — CC BY 4.0, атрибуция на странице.
