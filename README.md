# Qeralo — портфолио

Одностраничный статический сайт. Без сборки, фреймворков и внешних запросов: вся разметка, CSS и JS находятся в `index.html`, шрифты — в `assets/`.

## Как посмотреть

Откройте `index.html` в браузере — сборка и локальный сервер не нужны.

При желании можно подать папку через любой статический сервер:

```sh
npx serve .
```

## Структура

```
index.html                  страница: разметка, CSS и JS
assets/fonts.css            только @font-face
assets/fonts/               Manrope (кириллица + латиница), OFL.txt
```

## Особенности

- Собственные шрифты Manrope (Variable, `wght` 200–800); кириллица и латиница в отдельных поднаборах. Лицензия — [SIL Open Font License](assets/fonts/OFL.txt).
- Иконки Solar Linear (480 Design, CC BY 4.0) встроены в страницу как SVG-спрайт; атрибуция указана в футере и в HTML-комментарии. Иконка GitHub взята из Material Design Icons (Apache-2.0).
- Скролл-анимация 3D-сборки сделана чистым CSS-трансформом: JS лишь выставляет CSS-переменные `--p` и `--scroll`.
- Демо «Резиновая сетка» работает и на телефоне: рамку можно тянуть пальцем или выбрать размер кнопкой.
- Вопросы раскрываются с плавной печатью ответа; во время набора блок сохраняет свою высоту, поэтому страница не дёргается.
- Сайт читается и без JavaScript, поддерживает `prefers-reduced-motion` и светлую/тёмную тему.
