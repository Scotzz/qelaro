# Заметки по проекту

## Что это

Одностраничный статический сайт (портфолио Qeralo) с собственными шрифтами. Без сборки и внешних запросов.

```
index.html                  вся страница: разметка, CSS и JS в одном файле
assets/fonts.css            только @font-face
assets/fonts/               manrope-cyrillic.woff2, manrope-latin.woff2, OFL.txt
```

- Весь CSS лежит в одном `<style>`, весь JS — в одном `<script>`. Никаких фреймворков, сборщиков и внешних ресурсов.
- Нет `package.json`, лок файлов и инструментов сборки/линтинга. Страница открывается прямо из `index.html`.
- Пути к шрифтам в `assets/fonts.css` относительные (`fonts/…`), а не от `index.html`. При переносе CSS их нужно поправить.

## Шрифты и иконки

- Manrope переменный, `wght` 200–800, два поднабора (кириллица и латиница). Лицензия — `assets/fonts/OFL.txt` (OFL обязательна при локальном размещении).
- Кириллица проверена по `cmap`: все 64 русские буквы + Ё/ё. Объединённые поднаборы также покрывают `« » — … • × №`.
- Отсутствуют глифы `→` и `₽` — они уйдут в системный шрифт. Ещё нет `≈` и `✓`: используйте слова или иконку галочки из набора.
- Chillax не содержит кириллицы (0 глифов в U+0400–04FF), поэтому для русского текста не подходит.
- Иконки Solar Linear (480 Design, CC BY 4.0) встроены в страницу SVG-спрайтом в начале `<body>` (`<symbol id="i-…">`), используются как `<svg class="ic"><use href="#i-…"/></svg>`. Атрибуция есть в футере и в HTML-комментарии — оба места нужны по условиям CC BY.
- Иконка GitHub взята из Material Design Icons (Apache-2.0), также встроена спрайтом.
- Favicon — встроенный data-URI SVG, отдельного запроса `favicon.ico` нет.

## Как устроена страница

- Заголовки используют фиксированное `font-variation-settings:'wght' 700`, остальной текст — `font-weight: 400`.
- Скролл-анимация 3D-сборки сделана чистыми CSS-трансформами: JS только выставляет `--p` (0→1) на `#deck` из позиции прокрутки, вся геометрия считается через `calc()` от `--p`.
- `.build` использует `overflow-x: clip` — повёрнутая сцена намеренно выходит за пределы по горизонтали. Нужно именно `clip`, не `hidden`: `hidden` сломал бы `position: sticky` внутри.
- Значение `--p: 1` по умолчанию в CSS означает, что без JS показывается собранная страница.
- Для полоски прогресса JS в том же `requestAnimationFrame` выставляет `--scroll` (0→1) на `:root`.
- `prefers-reduced-motion` убирает «взлётную полосу», отключает 3D, штамп, прорисовку подчёркиваний, пульсацию и покачивание.
- Кнопки копирования в контактах: `navigator.clipboard.writeText` с fallback на `execCommand` для `file://`. После копирования меняется `<use href>` на `#i-check`, результат объявляется через `#copyLive` и возвращается обратно через 1,8 с.
- Панель «Не верьте на слово» измеряет страницу прямо в браузере: размер в байтах через `Blob`, число узлов DOM, внешние `http(s)`-ресурсы и время `document.fonts.ready`. Значения анимируются, если не включён reduced motion. HTML считается как байты `outerHTML`, CSS и JS — только встроенные блоки; это указано в примечании панели.
- Часы показывают только локальное время посетителя — без обещаний по времени ответа.
- Стрелки в вопросах требуют явного начального `transform:rotate(0deg)`: в Edge переход от `none` к `rotate(180deg)` на встроенном `<svg>` застревает в исходной матрице.
- Элементы с классом `js-only` скрываются блоком `<noscript>` — без JavaScript страница остаётся читаемой.

## Что пока не добавлено

Цен и сроков в текстах нет — их намеренно не придумывали. Перед добавлением блока с ценами их должен предоставить владелец.
